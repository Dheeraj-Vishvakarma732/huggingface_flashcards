# Hugging Face Flashcard Generator

A simple Python application that uses a Hugging Face AI model to generate 5 study flashcards on any topic.

## Features

- Generate 5 flashcards for any topic
- Short question and answer format
- Uses Hugging Face Inference API
- Measures AI response time

## How to Run

1. Install dependencies:
   `pip install -r requirements.txt`

2. Set your Hugging Face token as `HF_TOKEN`.

3. Run:
   `python app.py`
